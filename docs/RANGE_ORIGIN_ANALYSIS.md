# 范围来源诊断分析：远端初始覆盖不足与早期级联丢失

日期：2026-09-08。
数据目录：`eval/baseline_diagnostics/v2_vis_20260908_165325_258043/`。

## 结论与优先级

本次联合统计已经能够把下一轮实验收敛到两个独立问题：

1. **初始搜索范围的远端覆盖不足**。不是主要由 S1 少采最后三个基础间隔导致；必须将范围设置因素从模型改进的收益中单独区分。
2. **S1→S2 收缩丢掉正确候选，形成后续难以纠正的大误差**。这应作为针对 VisMVSNet 级联机制的首要方法改进位置；S2→S3 更多表现为大量边界/遮挡像素的进一步丢失。

下一项先做一个可解释的固定权重干预：只增加 S1 远端候选，保持原间隔和已有候选位置。该对照用于确认输入支持范围的实际影响，不当作等算力新方法。方法主线则固定为 S1→S2 的候选保留/恢复，暂不同时改变特征提取、融合头和损失。

## 1. 核验

- manifest：completed、returncode=0、full_val，range_origin_diagnostics=true，无 max_samples 限制。
- 882 张参考图、18 个 scan，scan 集合与 Val 列表完全一致。
- 172,872 条逐图联合记录、196 条汇总；逐条重新汇总原始计数、误差和、距离和、最大距离及所有派生比例，均与 summary 一致。
- 每个图像/区域/比较内，各互斥分组构成 all，像素和可加总指标守恒。
- 与上一轮共同记录的模型/数据源码及 Val 列表哈希一致。当前本地文件统一 CRLF/LF 后也与本次运行记录一致。
- 常规全图 Abs 为 5.0226012 mm，上一轮为 5.0226207 mm。所有区域、两种聚合的 Abs 最大差约 0.0006673 mm；Acc2 最大差约 0.003199 个百分点，结果可比。
- 本轮只离线分析已保存 CSV，没有运行模型或核验权重文件内容。

本报告中的联合指标均在固定 GT 网格上，用 nearest 选择各阶段区间端点和 S3 深度。所有误差贡献的分母是同一区域的共同网格 S3 绝对误差总和。这不同于常规 bilinear 深度评估和上一轮各阶段原始格点统计，不能把不同口径的 Abs 混排。

## 2. 两种失效的贡献已经分开

| 区域 | S1内→S3外 像素% | 该组最终误差贡献% | S1外→S3外 像素% | 该组最终误差贡献% |
| --- | ---: | ---: | ---: | ---: |
| 全图 | 3.322 | 46.625 | 1.409 | 26.741 |
| 大视差 | 5.200 | 37.485 | 6.321 | 48.636 |
| 遮挡 | 17.372 | 60.054 | 4.950 | 28.105 |
| 大视差∩遮挡 | 16.519 | 47.179 | 11.885 | 45.747 |
| 边界 | 18.847 | 63.335 | 3.139 | 21.352 |

解释：

- 大视差总体对初始覆盖不足尤其敏感；仍在初始范围之外的像素贡献约 48.64% 的最终误差。
- 遮挡与边界的主要误差集中在“原本覆盖、后续丢失”的组，分别贡献约 60.05%、63.34%。
- 大视差∩遮挡的两种失效贡献接近：47.18% 与 45.75%，因此只处理其中一种并不足以覆盖主要问题。
- 这些是分组关联，不证明组内每个错误的唯一因果来源，也不是对应改动的可实现收益比例。

限定到 S1 本来覆盖的像素后，大视差∩遮挡中后续丢失组贡献该条件子集约 88.86% 的绝对误差，遮挡约 84.44%，边界约 80.90%。因此级联问题不能仅由初始范围不足解释。

当前模型也存在恢复能力：大视差∩遮挡中，约 37.76% 的初始范围外像素到 S3 回到范围内；大视差约 50.02%。评估新方案时应保留这部分恢复统计，不能假设初始越界必然永久失败。

## 3. 初始问题集中在远端，端点差不是主因

| 区域 | 超出数据原始上界的像素% | 条件平均越界 mm | 最大越界 mm |
| --- | ---: | ---: | ---: |
| 全图 | 2.672 | 74.368 | 311.873 |
| 大视差 | 11.741 | 77.463 | 311.873 |
| 遮挡 | 7.378 | 79.559 | 311.873 |
| 大视差∩遮挡 | 17.874 | 82.978 | 311.873 |

低于原始下界的像素占比很小：全图约 0.006%，交集约 0.022%。因此最先检验的方向是远端支持范围，而非对称地向近远两端扩展。

S1 实际使用 `[start, start+188Δ]`，数据名义原始范围到 `start+191Δ`。但数据范围内、被 S1 额外漏掉的像素：

- 全图仅 0.210%，贡献约 1.035% 的最终误差；
- 大视差仅 0.879%，贡献约 1.784%；
- 大视差∩遮挡仅 1.200%，贡献约 1.938%，平均越界约 4 mm。

相较于交集 17.874% 的像素已经超出数据原始上界、平均超出约 83 mm，补齐三个基础间隔无法解释或处理主要的初始漏覆盖。上述误差贡献不是整个网络修改后的因果收益上限，只用于判断该分组的重要性。

这确认了范围支持的现象，但尚未证明相机标定错误或深度单位错误。范围规则本身可能偏窄、有效掩码也可能包含更远表面；不能仅凭统计把“范围外 GT”称为错误 GT 或直接删除它们。

## 4. S1→S2：数量少、后果重；S2→S3：数量多、错误相对较小

| 大视差 | S1→S2 | 1.792 | 179.343 | 24.522 |
| 大视差 | S2→S3 | 4.098 | 48.531 | 15.178 |

本表比较相邻阶段，不表示已记录全部逐像素三阶段历史。相邻比较的失效组可能重叠或包含后续恢复的像素，不能把两行贡献直接相加。

在交集区域，S1→S2 丢失组的 GT 平均在 S2 区间外约 101.56 mm；该组到 S3 的平均区间距离仍约 166.76 mm。这表明大错误不只是略微超出范围的边缘情况。只在错误中心附近小幅调整间隔，缺乏足够的恢复空间。

还可以利用同网格两两统计给出严格上下界，无需假设两个分组互斥：

```text
早期丢失且到 S3 仍未恢复的误差和
  >= S1内→S2外 的误差和 - S2外→S3内 的误差和
  <= S1内→S2外 的误差和
```

交集中，上述持续失效的误差占总误差约 32.079%–32.231%；占全部 S1内→S3外 误差约 67.99%–68.32%。因此，在已由级联新增丢失的严重误差中，约三分之二可定位到早期收缩后的持续失效。这是优先改 S1→S2 的定量依据。

## 5. 逐 scan：初始问题集中，级联问题更普遍

交集区域，S1内→S3外 的误差贡献超过 S1外→S3外 的 scan 有 14/18 个；其中 13/18 个 scan 的级联新增丢失组贡献超过本 scan 总误差的一半。

三个高误差场景的交集误差分解：

| scan | 后续新增丢失贡献% | 初始外且持续外贡献% |
| --- | ---: | ---: |
| scan37 | 5.46 | 93.57 |
| scan28 | 27.49 | 67.29 |
| scan82 | 16.59 | 80.12 |

去掉这三个场景，剩余场景的交集误差有约 78.96% 来自 S1内→S3外；遮挡为 80.34%，边界为 74.62%。因此：

- 初始远端支持对总体大视差指标和少数高误差场景影响很大；
- 级联候选丢失是更普遍的模型问题，适合作为方法主线。

不能只通过改善这三个场景的初始范围，便宣称网络已经解决普遍的遮挡问题；也不能因其集中而忽略它们对总体误差的贡献。

## 6. 下一项实验：一个范围干预、一个方法原型，顺序执行

### 先做固定权重的 S1 远端覆盖对照

候选对照：S1 深度数从 48 增至 64，S1 间隔尺度仍为 4，起点不变；S2/S3 保持 32/16、间隔尺度 2/1，其余设置与基线完全一致。

这会保留原有前 48 个假设的位置，并增加 16 个远端假设，S1 末端由 `start+188Δ` 移到 `start+252Δ`，增加 `64Δ` 支持。该数值是一个预先固定的诊断候选，不是由每张 Val GT 动态决定，也不能保证覆盖最大约 312 mm 的远端越界。

目的：检验新增远端支持是否减少初始持续失效、最终 Abs 是否随之改善。先用相同已训练权重进行推理干预；改变推理深度数会改变概率/正则化分布，结果不能直接替代相同配置重训结论。

成本：S1 平面数增加约 33.3%，不等于全网耗时增加同样比例；实际时间/峰值显存需记录。它不是等预算消融，不能把收益全记为新结构能力。

判据：

- 初始持续越界减少且 Abs/Bad8 改善：确认范围规则对指标的重要性，再建立独立的覆盖校准基线。
- 覆盖改善但 Abs 不改善：说明“能搜到”和“能选对”仍未同时解决，不继续盲目增加深度数。
- 同时检查 S1内→S3外 和已覆盖区域的精度，避免较大范围破坏原有匹配。
- 保持全有效像素评价，不删除范围外 GT；对照参数只作为统一规则，不按单张 Val 真值调范围。

### 方法原型优先只改 S1→S2 候选传递

目标：当前景/背景竞争或 S1 中心出错时，S2 仍能保留正确候选的恢复机会。

保留固定的特征网络、源融合与损失；只在 S1→S2 对候选中心/分支做一项改动。分离峰或可信 pair 候选是可验证的设计选择，但当前 CSV 不含概率分布，不能声称已证明“全部错误由多峰均值造成”。原型还需检查候选本身是否包含正确表面。

真正的方法对照保持总假设预算可比，并同时报告：S1内→S2外、S1内→S3外、交集/边界 Abs、Acc2、Bad8、逐 scan 结果、时间和显存。覆盖增加但误差不降不算通过。早期模块获得独立收益后，再考虑 S2→S3 和遮挡可靠性校准。

本轮完成离线结果审计与上述实验定义；没有修改模型、训练设置或启动这些新实验。
