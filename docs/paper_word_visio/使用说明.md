# 论文与图表文件

`大视差与复杂遮挡深度估计论文.docx` 为完整中文论文，包含摘要、引言、相关工作、方法、实验设置、结果分析、讨论、结论、参考文献和附录。正文与附录保留 View3、View5 的八组实验、区域指标、相对变化和实际场景可视化。使用通用论文版式，宽表与多子图页面采用横向排版。

公式为 Word 原生公式；正文、图注和数据表可直接编辑。可视化由真实导出的深度、误差与掩码图组成，子图分别嵌入，方便替换与调整。图像着色仅用于显示，数值分析使用原始误差。

`论文图表_可编辑.vsdx` 为原生 Visio 文件，共 10 页：

1. 总体框架：三级深度估计及 A/B/C 的具体作用位置。
2. ABC 模块：三个模块的数据输入、运算步骤与输出关系。
3. A 遮挡监督：逐源几何标签与监督流程。
4. B 自适应范围：概率统计、搜索半宽、候选生成流程。
5. C 假设融合：逐候选源视图权重与匹配聚合流程。
6. 训练推理流程：训练监督路径与推理数据路径。
7. View5 区域改善：八组配置在不同区域的 Abs 相对变化。
8. View3 区域改善：八组配置在不同区域的 Abs 相对变化。
9. 两套消融汇总：完整方法相对 Base 的区域误差变化。
10. 阈值准确率：两套实验八组配置的 Acc2、Acc4、Acc8。

Visio 内的框、文字、连接线和统计图元素均为可编辑对象。调整后可以导出 PNG/SVG 并替换 Word 中对应的图。统计图数字为本次结果的静态值，修改源数据后需同步调整数字与图形。真实深度、误差和遮挡掩码以图像保留，不将其转成虚构的矢量结果。

`visio_previews` 提供每页图表的 PNG 与 SVG 导出版本；`scene_panels`（打包文件内）提供论文使用的 12 个场景，每个场景含独立子图和组合图，按 View3/View5、困难场景类别和样本名组织。

论文数据、公式与正文以 `docs/PAPER_DEPTH_ESTIMATION_WITH_VISUALIZATIONS.md` 为来源，本次生成没有修改该 Markdown 文档及原始实验 CSV。导出与核对脚本保存在项目 `tools` 目录。
