## 1. 已纠正的实质问题

| 项目 | 前稿问题 | 修订 |
| --- | --- | --- |
| 不确定性定义 | 图中写 $-\log U$，未说明网络输出已经是对数尺度 | 网络输出统一写 $u$，基础 logit 为 $-u$，正权重为 $\exp(-u)$；正尺度为 $\exp(u)$ |
| 两种不确定性 | 易将成对可靠性与深度分布标准差混为一谈 | $u_s^t$ 为成对对数尺度，$\sigma^t$ 为融合概率的深度标准差；后者才进入范围生成 |
| A 的特征来源 | 泛称匹配特征头，没有准确交代输入 | 成对概率→熵 $E$→二维共享编码 $H$→对数不确定性/可见性双头 |
| Focal 类别平衡 | 写固定 $\alpha$ 和像素数归一化，且与融合 $\alpha_s$ 重名 | 按有效监督样本计算 $c_+,c_-$，用类别权重和归一化；融合统一写 $w_{s,k}$ |
| C 的输入 | 候选相关残差的输入不够具体 | 八通道隐变量、$\tanh$ 得分、成对概率、归一化深度坐标，共十一通道 |
| C 的融合对象 | 正文写匹配特征，图写正则化隐变量 | 统一为第一次正则化后的 $V_s^t$ |
| C 的有效源集合 | 前稿添加了当前候选处几何有效集合，实际融合没有此显式筛选 | 公式对实际输入的 $S$ 个源视图归一化；遮挡标签只作训练/诊断 |
| 范围宽度单位 | width 容易被理解为 mm | CSV 的 width 是区间宽度/输入基础深度间距，为无量纲倍数；Abs 是深度误差 |
| 训练深度损失 | 前稿写了未核定的平滑 L1 | 当前实现使用除以基础间距的 L1，明确写入式(19) |
| 辅助损失 | $\mathcal L_{base,aux}$ 过于笼统 | 明确成对 L1、不确定性 NLL、A 的 Focal 和可选 C 的最近真值候选监督 |
| A 的遮挡作用 | 只说明额外分类监督 | 补充可见区域成对深度损失及遮挡区域不确定性项的误差停止梯度 |
| 阶段间梯度 | 前稿没有说明 | 当前前向没有对前级深度/标准差 detach；与被遮挡成对误差的 stop-gradient 区分 |
| 文献顺序 | 预先分配编号，首次出现为 [2]、[9] 等 | 完整论文按正文首次引用排序，文末同步重排；生成器重复运行保持一致 |

## 2. 公式来源与推导边界

| 公式 | 性质 | 核对依据 |
| --- | --- | --- |
| (1) | 已标定相机反投影与相对变换 | 光轴深度 $d$；齐次像素、内参和特征尺度一致 |
| (2) | 组相关代价体及第一次正则化 | 原 Vis-MVSNet Figure 2、3.1 节；当前匹配通道为八组 |
| (3)—(4) | 几何一致性定义可见/遮挡标签 | 深度差容差为 mm；越界不算遮挡，前方不一致不算负类 |
| (5)—(7) | 可见性双头与类别平衡 Focal BCE | Focal 原理来自 Lin 等；本任务类别平衡与归一化是当前实现，不是原论文原封不动的公式 |
| (8)—(11) | 标准差指导半宽、边界求交、线性采样 | 不确定性范围具有 UCS-Net 研究基础；具体裁剪上下界来自本项目配置 |
| (12)—(15) | 十一通道残差预测及源视图归一化融合 | 残差、网络结构、融合张量逐项核对；指数权重/权重和与源视图 softmax 数学等价 |
| (16)—(18) | 概率归一化、期望与标准差 | 深度维 softmax；方差单位为 mm²，标准差为 mm |
| (19)—(21) | 归一化 L1、成对监督与联合损失 | 当前损失实现；不确定性 NLL 继承原 Vis-MVSNet Laplace 模型 |

原 Vis-MVSNet 3.2 节明确说明实际预测 $S_i=\log U_i$；3.3 节使用 $\exp(-S_i)$ 加权隐变量。本文将该变量重命名为 $u_s^t$，避免与源视图数量 $S$ 混淆。网络字母可以由作者定义，但物理意义、张量形状、归一化维度和训练方式不能随意改变。

来源：[Vis-MVSNet](https://arxiv.org/abs/2008.07928)、[UCS-Net](https://arxiv.org/abs/1911.12012)、[Focal Loss](https://arxiv.org/abs/1708.02002)。

## 4. 仍须由训练记录确认的信息

1. 产生八组 CSV 的确切 Git commit、训练命令、损失权重、阶段候选数量和间距倍率。现有 CSV 记录了范围倍率、残差倍率和检查点路径，但不能完整恢复训练配置。
2. $\lambda_C$ 是否启用、A 的 Focal 指数、遮挡标签容差以及对应检查点的训练方式。当前公式明确列出可选项，不能由推理结果倒推训练权重。
3. DTU 图像、真值深度与相机内参的尺度：沿用现评测器可保证与现数字相符，仍需确认预处理符合几何约定。
4. “多数源视图遮挡”的现评测定义是 $2n_{occ}\geq n_{comparable}$，即至少一半可比较源视图，而非严格超过一半；可比较源视图仅有一个时也会进入该区域。
5. “大视差”使用真值相机重投影的最大二维位移并逐图取第 80 百分位以上；这是未校正多视图的重投影位移指标，不等同于平行双目的水平视差。现实现的最大位移统计没有筛掉越界源投影，若改变定义需重跑全部八组，不能只改文字。
6. 局部 ROI 的指标仅说明该裁剪的现象，不能替代全测试集的像素加权汇总。C 的最近真值候选权重是 GT 诊断，不能称为推理时使用 GT。
