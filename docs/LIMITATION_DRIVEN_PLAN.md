# 从 Vis-MVSNet 的局限出发收敛改进方向

日期：2026-09-08。依据：当前源码、官方实现、已有 Val CSV 与 manifest。本文区分代码事实、结果现象和待验证假设；不把候选结构当作已证明有效的方法。

## 1. 研究问题

**大视差下的匹配歧义与遮挡，使部分双视图证据不可靠；不可靠证据经过融合和单中心级联收缩，可能把正确表面排除在后续搜索之外。**

沿这条链路研究两个问题：怎样使用可靠的源视图证据；怎样把仍有可能正确的深度候选传到下一阶段。模块数量由证据决定，不预设必须得到三个模块。

Vis-MVSNet 已经用双视图深度分布的不确定性指导源视图融合。因此“增加遮挡感知”本身不足以解释新方法的必要性，必须指出原有不确定性代理在什么情况下失效。

来源：[原论文](https://arxiv.org/abs/2008.07928)、[官方实现](https://github.com/jzhangbs/Vis-MVSNet)。下文关于失效机制的推导来自对这些机制及本地代码的分析，并非原论文已证明的结论。

## 2. 基线边界要先明确

- `models/vismvsnet.py` 的特征提取是逐层下采样 CNN；本地 `../Vis-MVSNet/core/model_cas.py` 的官方特征提取使用多尺度 UNet。两者 3D 正则化实现也不同。当前结果应称为“本仓库 Vis-MVSNet 复现基线”的结果。
- 官方级联中心使用上一阶段 `est_depth.detach()`；本地中心传递没有同样的显式 detach，不能假定训练梯度路径完全一致。具体路径还受 warping 的 no_grad 影响。
- 本地 `module.py` 采用与 `align_corners=True` 对应的 `(W-1)/2` 坐标归一化，`grid_sample` 却没有显式指定 `align_corners`。应先在实际训练 PyTorch 环境核验恒等投影和已知平移；若修复，需要单独记录并重训所有相关对照，不能把坐标修复收益算成新模块贡献。
- v2 的配置路径位于 `model_variants.py`，实际上统一构造 `vismvsnet_oa.py` 中的模型；分析旧 `vismvsnet.py` 的共同结构后，仍需确认实际运行入口。

这些是基线可解释性的前置核验，不构成新的研究模块。本轮没有修改训练模型、采样和 checkpoint。

## 3. 已有实验到底支持什么

完整数据见 [联合审计](V2_RESULT_AUDIT.md)。四组均为训练 3 视图、seed=1、16 epochs、batch=4，推理及区域定义 5 视图，Val light=3，各自 best_2mm。

四份 manifest 的所记录源码/列表哈希及公共运行参数相同；四组逐图区域键和像素数相同；已用 all_metrics.csv 重算核对两种 summary 聚合。未重跑模型或验证 checkpoint 内容，所记录哈希也没有覆盖全部依赖。

| 全图 | 5.0226 | 5.0196 | 5.0780 | 5.0970 |
| 大视差 | 12.6562 | 12.5258 | 12.9587 | 12.5590 |
| 任一源遮挡 | 22.7834 | 22.6753 | 22.9718 | 23.2448 |

- M2：该轮像素加权 Abs 七区域均退化。旧五视图仅监督实验曾有改善，说明效果依赖设置，不能把其正向结论直接移到当前三视图实验。
- M3：全图 Acc2 从 80.5503% 升到 81.4989%，但边界 Abs 从 19.9799 增到 21.3444 mm，18 个 scan 中 16 个退化，边界 S3 coverage 从 79.1230% 降到 77.8919%。这是需要解释的精度指标权衡，不是全面改善；误差尾部分布尚需另测。

基线 S3 coverage：全图 95.4095%，大视差 88.5554%，遮挡 78.2526%，交集 71.6871%。这支持优先诊断级联范围丢失，但不能单凭区域均值判定所有大误差都由范围丢失造成。

旧同一 vis 权重的 M3 扩展对照还表明：遮挡 coverage 从 79.6775% 升至约 81.2900%，Abs 却从 21.1716 增到 21.2339 mm。包住 GT 与选对深度是两个问题。该旧实验使用不同训练设置，只作机制诊断，不能与本表直接混排排名。

## 4. 遮挡：原有不确定性代理的具体限制

在 `SingleStage` 中，每个源视图独立得到深度分布 P_s(d)，计算熵后输入 UncertNet：

```text
u_s(x) = U(H(P_s(d | x)))
w_s(x) = exp(-u_s(x))
F(d,x) = sum_s w_s(x) F_s(d,x) / sum_s w_s(x)
```

这不是“没有可见性”，而是用匹配误差相关的不确定性间接表达可见性。其限制是：

1. 熵压缩了分布信息。熵对深度 bin 的排列不敏感，正确单峰和错误单峰可能同样低熵；前后景竞争和重复纹理也未必能仅凭熵区分。UncertNet 有空间上下文，但没有直接读取跨源一致性或完整代价曲线。
2. 原权重对整个深度轴相同。一张源图在某个假设下缺乏支持，不能通过同一像素的一个标量精确表达各个假设的有效性。
3. 源视图归一化只保留相对权重。若所有源视图都缺乏证据，给所有源权重乘同一个很小的系数，归一化后完全抵消。当前 M1 中所有源都无效时的 0.05 下界也有此性质。分母有定义不代表存在可靠证据。
4. 投影有效性只说明点在相机前方、图像内，不说明没有被前景遮挡。把两者混用，会把视场问题错误描述为遮挡问题。

**主线 A：面向证据可靠性的融合校准。**

先分开评估投影有效性和现有 M1 残差头，避免两个变化捆在一个“单模块”里。随后仅在诊断确认需要时，用完整匹配曲线的峰值/竞争峰、跨源兼容性和投影有效性补充熵，估计假设级可靠性。遮挡标签仅在训练时从源 GT 构造，推理输入必须来自图像、相机和预测信息。

候选权重形式可写成 `w_s(d,x) = V_s(d,x) * exp(-u_s(x) + r_s(d,x))`，但 r 的解释应是“匹配可靠性残差”，不能未经监督和校准就叫作物理遮挡概率。跨源一致性也可能形成错误共识，需要保留原 pair evidence 并检查少数正确视图被排斥的情况。

对于所有源无有效投影的情况，明确输出零融合证据并保留 support 标记，或使用单独的无观测分支；不能用归一化下界暗示有效观测。对于图像内部全部遮挡，仍需可靠性估计识别，并检验其漏判。无证据区域允许依赖空间先验，但应报告其置信度和误差，不能只丢弃困难像素后报告更高精度。

需要证明：在相同区域和深度假设预算下，GT 邻近假设上分给遮挡源的权重下降，给可见源的有效权重保留，范围内的误差下降。分类 accuracy 提高本身不足以证明融合变好。

## 5. 大视差：采样敏感性和候选丢失

大视差不等于特征匹配窗口不够大。Vis-MVSNet 已经用相机与深度假设进行几何 warping；需要进一步区分宽基线外观变化、深度采样误差和级联丢失。

对平行校正双目，有 `p=fB/z`，相邻深度假设引起的投影变化约为：

```text
|Δp| ≈ fB / z² * Δz
```

在基线较大或距离较近处，同样的 Δz 可能跨过较大的源图像距离。一般非校正多视图应计算 `J_s(x,z)=||∂π_s(x,z)/∂z||`，并在该阶段特征坐标下检查 `J_s * Δz`。上述公式是校正双目的解释示例，不能直接代替 DTU 的完整投影。

本地级联还将整个概率分布压缩为期望深度，对该单值双线性上采样，再构造固定的局部均匀假设。例如两个表面分别位于 500 和 700 mm，近似等概率时均值约为 600 mm；如果下一阶段半范围不足 100 mm，就可能把两个表面都排除。空间上的前后景双线性混合会进一步引入类似问题。

现有 M3 只重分配四个粗深度邻居的插值权重。若这四个值都已丢掉正确表面，其凸组合无法找回表面，因此它只能处理部分中心上采样错误。

**主线 B：保留竞争表面的级联候选。**

先测正确表面是“在当前范围内但采样太稀”，还是“在期望中心收缩后被排除”。前者优先做独立的逆深度/投影敏感性采样对照；后者优先保留前一阶段的两个分离峰或可信 pair 候选，在下一阶段分配局部假设预算。不要同时改中心、间隔、范围和特征提取。

候选原型约束：

- Stage 2/3 总深度预算仍为 32/16，新增分支的显存和时间单独记录。
- 单峰像素尽量保留原局部密度；有分离竞争峰时才分配第二局部候选。简单 top-k 往往都在同一峰，需要峰间距约束或局部极值选择。
- 不直接围绕两个峰的均值采样；保留两个表面的身份。
- 多峰非均匀假设不能不加说明地拼接后沿用普通 3D 卷积：相邻 bin 的物理间隔已经变化。原型需用共享权重分别正则化均匀局部分支，再做分支评分，或显式引入深度间距。两种方案各自独立验证，不能把这项实现代价忽略。
- 额外候选来自预测分布，不在推理中读取 GT。若前一阶段所有峰都错，双峰方案同样可能失败；再考虑有限探索预算，不能承诺一定找回真值。

需要证明：进入下一阶段前的 GT 候选保留率提高，假设到 GT 的最近距离没有因稀疏化明显变差，且最终边界/遮挡 Abs 和高分位误差改善。只提高 min/max coverage 不够。

## 6. 先做能够区分原因的诊断

首项“原始阶段分辨率的范围内/外误差分组”现已提供运行入口，操作见 [下一次诊断](NEXT_RUN.md)。其余 pair 权重、投影敏感性及 oracle 干预仍是后续待实现诊断。

现有 CSV 无法事后恢复以下逐像素、逐假设统计，需要在服务器上对固定 Val 样本重新前向一次，并输出诊断，不需要先启动新模型训练。

| 诊断 | 要回答的问题 | 对应下一步 |
| --- | --- | --- |
| 逐阶段 GT 是否在范围内；在范围内/外分别的 Abs、Acc2、误差贡献 | 是融合/匹配失败，还是搜索排除了真值 | 决定先 A 还是 B |
| 相邻假设的投影位移、最近假设距 GT 的深度/投影误差 | 大视差是否伴随采样不足 | 决定是否独立验证逆深度或自适应间隔 |
| pair 低不确定性但高深度误差的比例、遮挡标签、归一化权重 | 熵代理是否给错误源高权重 | 决定可靠性校准输入 |
| 原标量融合、投影掩码单独启用、残差头单独启用 | M1 哪一部分在发挥作用 | 避免把两因素收益混归因 |
| GT 遮挡源 oracle 抑制，保持相同预测假设；单列全无可见源 | 理想源选择最多有多大收益 | 判断遮挡融合是否值得优先研究 |
| GT 中心 oracle 与预测均值中心，保持相同数量/间隔 | 中心错误的可恢复空间有多大 | 判断候选保留优先级 |
| 均值中心与分离峰候选保留率 | 原分布是否还保留正确候选 | 判断双峰原型是否有依据 |

Oracle 仅用于故障定位，属于带 GT 的诊断干预，不能作为可部署方法或与真实模型混排；也不保证在未经重训的模型上单调改善。每次只改变一种因素。

当前 coverage 是上采样 min/max 后的包络覆盖率。新增诊断还应在各阶段原始分辨率计算假设到 GT 的最近距离，并保留固定 GT 区域映射。不能用插值后的包络替代实际离散候选的精度。

当前 large_disparity 是每图跨源最大原始像素位移的前 20%，包括旋转带来的位移，且位移计算发生在有效投影筛选之前。它不是严格的大平移基线/大三角测量视差。保留历史掩码以便对照，另加有效投影下的视差敏感性或视线夹角分桶，检查结论是否仍成立。

训练遮挡标签使用 nearest 采样源深度，区域评估使用 bilinear；边界处定义可能不一致。新增诊断应明确采样口径，并报告边界不确定带，不能静默改历史掩码重新排名。

## 7. 实验顺序与准入条件

1. 固定当前 v2_vis 为历史参照，完成投影坐标和官方复现差异核验；需要修复时建立单独基线记录。
2. 仅跑以上诊断，确认困难区域主要错误来源。当前证据足以优先诊断候选丢失，尚不足以宣布其为唯一主因。
3. 实现被诊断支持的一个最小改动，与同基线、同训练视图数/迭代数/深度预算对照。M1 可作现有最强候选之一；M2、M3 保留失败/权衡记录。
4. 使用预先约定的 Val 指标共同判定：大视差、遮挡、交集的 Abs/Acc2，全图及边界不发生明显退化；补充 P90/P95、误差超过 8 mm 的比例、逐 scan 胜负。容许退化幅度在运行前结合基线 seed 波动定，不在看到结果后选阈值。
5. 候选在多个配对 seed 上复验后再组合；组合必须相对较强单模块有增量。继续只使用 train/val，不用 test 调参。

