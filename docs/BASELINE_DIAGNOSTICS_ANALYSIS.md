# 基线诊断分析：初始范围覆盖与级联候选丢失

分析日期：2026-09-08。
数据目录：`eval/baseline_diagnostics/v2_vis_20260908_163221_923769/`。

## 结论

**当前严重深度误差主要集中在 GT 已经落到搜索范围外的像素；下一步优先研究搜索支持范围和候选传递。**

但不能把这一结论简化成“只要扩宽 Stage 3”或“已经证明双峰方案有效”。至少存在两种需要拆开的现象：Stage 1 初始全局范围已不覆盖部分有效 GT；后续阶段的局部范围又在边界、遮挡区域出现较多排除真值的情况。遮挡导致的错误匹配仍可能是上游原因，当前 CSV 没有源视图权重，不能排除该原因。

## 3. 固定当前区间时，最后一级精修存在明确限制

对每个像素定义区间约束误差下界：

```text
e_floor = max(d_min - GT, GT - d_max, 0)
```

当前深度通过 softmax 加权假设回归，输出在假设 min/max 区间内。因此固定本次每个像素的 S3 区间时，即使理想地在区间内任选深度，误差也不能低于这个距离。

- 大视差∩遮挡的实际原始网格 Abs：35.3037 mm。
- 相同区间下的平均误差下界：28.4654 mm。
- 即使达到理想区间内输出，也只能比当前值最多减少约 6.84 mm，即约 19.37%。

这支持优先改变“哪些深度仍可被搜索到”。它不否定改进上游融合：如果上游融合改变下一阶段中心，区间本身就会变化。它也不表示扩大范围后必然获得 80.63% 的改善。

范围内最近离散假设距 GT：S3 大视差约 0.6419 mm、遮挡约 0.6583 mm、交集约 0.6593 mm，明显小于各自范围内预测 Abs。仅在已覆盖区域增加均匀采样密度，尚无证据能解决主要大误差；该距离不是连续回归的量化误差下界，也不能代替投影空间采样诊断。

| --- | ---: | ---: | ---: |

| 遮挡 | 7.91 | 123.9315 | 35.47 |

S1 尚未使用前一级预测构造局部范围，所以这些越界不能归因于 S2/S3 的中心上采样。当前实现默认 S1 为 `d_start + arange(48) * 4Δ`，最后一个假设是 `d_start + 188Δ`；名义 192 个原始假设的末端是 `d_start + 191Δ`。两者存在末端差，但当前 CSV 没有上下界、原始区间或越界方向，不能认定这个差就是全部原因。

数据加载使用深度有效掩码；评估也未把有效 GT 限制到相机设定区间内。因此，初始范围和被评估 GT 支持域是否一致是必须先核验的事实，而非一个已确定的网络缺陷。

S1 范围外像素集中在部分场景：全图越界像素中，scan37/82/28 合计约 75.57%。S1 大视差∩遮挡区域的范围外比例分别为：scan37 83.45%、scan82 67.97%、scan28 44.19%。这些场景优先检查相机深度范围、坐标/单位、有效掩码与近远表面分布。

## 5. 结论不是由三个异常场景独自造成

按 scan 单独聚合：

- S3 大视差、遮挡、交集和边界四类区域，18/18 scan 的范围外绝对误差贡献均超过 50%。
- 大视差∩遮挡有 14/18 scan 的范围外绝对误差贡献超过 80%，各 scan 介于 73.30%–99.12%。
- 去掉 S3 总绝对误差贡献最大的 scan37/28/82 后，交集的范围外绝对误差贡献仍为 89.16%；大视差 77.38%，遮挡 84.77%，边界 80.27%。

此外，S1 原始格点上未观察到范围外有效 GT 的五个 scan（3、5、67、106、117），其 S3 交集仍有 17.31% 的范围外像素，贡献 88.35% 的绝对误差。这是后续局部范围问题值得独立研究的补充证据。

但不同阶段网格不同，不能把上述结果当作逐像素“从 S1 范围内转为 S3 范围外”的精确统计；精确拆分必须在同一 GT 网格记录联合掩码。

## 6. 更新后的研究优先级

### A. 先拆分初始范围问题和级联新增丢失

在同一个 GT 网格，分别记录数据提供的原始区间、S1 实际区间和 S2/S3 区间；只输出少量计数与越界距离即可，不需要先训练新网络：

1. GT 低于下界/高于上界各多少，平均及高分位越界距离。
2. GT 在数据原始区间内，但不在 S1 实际区间内的比例：确认是否只是末端覆盖问题。
3. S1 范围内且 S3 范围外的像素数与 S3 误差贡献：明确级联新增损失。
4. S1 范围外且 S3 范围外，以及 S1 范围外但 S3 找回的比例。

保留现有全有效像素指标，另报共同初始范围内的诊断分组；不能通过删掉范围外困难像素直接宣称性能改善。

若发现坐标、单位或区间实现问题，先建立修正后的基线，并与历史版本区分。若是相机给定范围不足，正式推理范围规则必须来自相机/输入信息或训练集统计，不能按每张 Val GT 动态构造范围。

### B. 方法主线优先做可恢复的级联候选传递

当前证据已支持把“局部区间丢掉真值”设为主问题；优先目标是让粗阶段有误或存在竞争表面时，细阶段保留纠正机会。

- 冻结当前特征、融合、损失定义，先设计一个候选传递改动，避免同时改变多个因素。
- 分离双峰/可信 pair 候选只有在上一级预测分布仍保留正确候选时才有作用。当前输出没有完整概率曲线，尚不能认定多峰是所有错误的根因或最佳方案。
- 对初始范围内的像素，检查新方法是否减少 S1-in/S3-out，并同时降低交集和边界 Abs；总假设预算保持 48/32/16 可比，报告时间/显存。
- 不沿用“覆盖提高即有效”的判断。旧同权重尾部扩展曾出现 coverage 上升而 Abs 变差，应同时看最近候选距离、Abs、Acc2、Bad8 和逐 scan 结果。

### C. 遮挡可靠性作为候选传递的上游解释和后续补充

当前范围内遮挡/交集 Abs 仍约 3.4–3.5 mm，S2 遮挡/交集范围内 Abs 约 8.7–9.0 mm，不能忽略上游匹配失误。下一次若记录 pair 概率/权重，可同时检查遮挡源的错误高权重是否诱发错误中心。

但本次结果不支持把 beta 搜索、仅增添可见性标签、替换 backbone 或边界上采样作为无条件的首要改动。它们应回答具体的上游失效问题，并通过后续区间和深度误差验证。

## 7. 证据边界

本轮只分析现有完整 Val 推理数据，没有重训模型，也没有改模型和评估口径。S1/S2/S3 网格分别为 64×80、128×160、256×320，GT/区域用 nearest 映射；训练损失中深度 GT 使用 bilinear，边界解释需注意采样约定。初始范围越界方向、逐像素阶段转移、概率多峰形态、源视图权重和物理遮挡的因果关系均未被当前 CSV 记录。

下一步不是继续堆模块，而是先把范围排除真值的来源拆清，再围绕可恢复候选传递做一个可验证的改动。
